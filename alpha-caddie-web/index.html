    Select Devig Books

    Choose which sportsbooks set the fair probability for EV, Kelly, and CS. For head-to-head markets you can also pick a method that changes how tight the fair price sits versus the posted lines. Apply & rescan updates the +EV table.

    Picking a method

    Methods only affect two-way matchups (not win/top-N outrights). They change how the app turns posted odds into a single fair price for EV, Kelly, and CS.

    Tip: Start with Multiplicative or Average. Use Worst case when you want the stingiest fair price for your side. If unsure, compare a couple of methods and see which CS lines up with how you read the market.

    Default

    100% weight

    One book carries full consensus weight.

    Split weights

    Apply saves preferences and rescans the +EV table.

    +EV Bets

    Scan matchup and outright bets in one place, sorted by Model EV so the biggest model edges float to the top. Narrow the list with the filters, then compare model prices to book prices column by column.

    Weather

    Use the same weather controls as Round projections. Set temp, wind, humidity, and Condition to match the expected day; that updates fair win chances on every row here. Choosing Default for condition resets the numbers to the baseline weather snapshot (then adjust sliders again if needed).

    Pricing

    Mode and Skill match the rest of the app: switch them when the goal is to weight recent form, this course, or a specific part of the game. Model % and Model EV update to reflect that choice.

    Toolbar

    Golfer
    Limit the table to one player.
    Market
    Show only one product type (for example round matchups, tournament matchups, win, top 10).
    Best books
    Pick one sportsbook to keep only rows where the best price for that bet is there, or All books to show every book.

    Hide longshots at that American price or longer. The default 10000 keeps odds below +10000.

    Table columns

    Model EV
    Edge vs the best available price at a glance: green for positive, red for negative.
    Kelly
    Suggested quarter Kelly stake in dollars from the bankroll above, using the boosted best price.
    Best book
    Where that best price lives; American odds (boosted when a boost is on).
    Golfer
    Who the bet is on.
    Model
    Fair American odds from Alpha Caddie round projections (Monte Carlo on projected scores), not DataGolf placement.
    CS
    Consensus “market fair” odds built from the books and weights in Devig. Use it to see how the model compares to the books you care about.
    Implied
    Win probability implied by the actual best price (after boost).
    Δ (delta)
    How far the model win % sits above or below that implied win %.
    Market
    Whether the row is a matchup type or an outright market.
    Bet
    The exact matchup wording or outright label.

    Devig settings

    Open Devig to choose which books feed EV, Kelly, and CS, split weights between them, and (for head-to-heads) pick a method that nudges consensus tighter or looser versus the board. Selected devig books are hidden from the bet offers so you do not bet into the same book used as the fair source.

    Tip: Try Average or Multiplicative first. Use Worst case when you want a cautious read on an edge.

    Live Prop Predictor

    Estimate full-round totals mid-event using the same stat columns as Round projections, plus how uncertain the remaining holes are from historical rounds (when hole-by-hole rows exist) and the usual Round projection spread scaled to holes left.

    How to fill it in

    Through … holes
    How many holes are finished (0–18), in order from Starting hole (e.g. start 10 → holes 10–18 then 1–9). Round score “to par” uses each hole’s par from the current course.
    Starting hole
    Shotgun or split-tee order: the first hole you played this round (1 or 10, etc.). Historical checkpoints use the same order when hole-by-hole data exists.
    Fairways hit
    Par 3s are not fairway holes; remainder mean and volatility use only par 4/5 holes from projections.json hole pars for this venue.
    Round score, birdies, pars, bogeys
    Where history includes hole-by-hole scores for a round, we learn the distribution of “what’s left” after your checkpoint and blend it with the model.
    GIR, fairways, putts
    Hole files rarely break these down per hole; we scale the Round projection mean and volatility to the holes remaining (fairways: par 3s excluded when course hole pars exist).
    Weather & pricing
    Uses the same global Weather and Pricing controls as the Round projections tab — adjust there first.
    Live line & prices
    When projections.json includes DraftKings round props, changing golfer or market fills DK line and Over/Under prices; otherwise defaults apply and you can edit.

    Parlay Pro

    Finds DraftKings round O/U parlays where the model’s joint win chance beats DK’s posted price. Leg correlation comes from historical co-hit rates in round_projection_vs_actual.csv (same player, same tee wave, same round, then sentiment-bucket averages).

    How to use

    Legs
    How many picks in the parlay (2–6). DK multiplies each leg’s price into one parlay ticket.
    Combo style
    All — best EV across styles. Same player — one golfer, different markets (e.g. O bogeys + O score = bad-day stack). Same market — same stat/side, different players in the same tee wave when possible. Negative correlation — good-day legs mixed with bad-day legs (e.g. U score + O bogeys); joint win % can beat DK’s naive stack.
    Min leg EV %
    Only consider legs your model already likes as singles at or above this EV.

    Odds columns

    Model fair
    DK-style correlated parlay fair from calibrated leg win rates (model blended toward DK devigged implied per market). Should land near the DK column when correlation rules match.
    Model + vig
    Same correlated stack using posted DK vig on each leg blended with model +vig singles.
    DK
    DK parlay price from posted leg odds with the same correlation rules (good↔good, bad↔bad, good↔bad). Unrelated same-market field stacks keep a small same-wave nudge only.
    EV
    (Model win % × DK parlay decimal) − 1. Win % uses the same calibrated legs and copula as Model fair.
    Win edge
    Model win % minus DK parlay implied %. Tooltip shows raw (unblended) model edge for comparison.
    ρ (rho)
    Average pair correlation from historical data when the leg-pair exists in the backtest file (e.g. O bogeys + O score for the same player). Falls back to round-level or good/bad-day bucket averages only when that exact pair is thin.

    Matchup Analysis Tool

    What each column header means on this tab.

    Prices & edge

    Golfer name
    Column for that side of the matchup.
    Model
    Estimated win probability for that golfer.
    Market
    Implied win probability from the posted prices.
    Edge
    Expected value vs fair at the price shown (positive is favorable).
    Odds
    American odds for that golfer at the listed book.
    Best Book
    Best decimal price among the same sportsbooks used on the +EV tab (respects your Devig book toggles).

    Strokes gained vs field

    Shown for head-to-head markets only. The section is hidden for 3-balls.

    Metric
    Stat being compared on that row.
    Golfer columns
    That golfer’s value for the metric, with a bar for scale.
    Field %
    Share of the field with a strictly lower value on that metric (higher is better).
    Advantage
    Which golfer leads and by how much on that row.

    Metric definitions

    SG: Total
    Overall DataGolf skill rating in strokes gained per round versus the field.
    SG: Tee-to-Green
    Combined non-putting skill: off the tee, approach, and around the green.
    SG: Off the Tee
    Driving skill after tee shots, including distance, accuracy, and position gained.
    SG: Approach
    Iron and approach-shot skill after the tee shot before short game or putting.
    SG: Around Green
    Short-game skill near the green, excluding putting.
    SG: Putting
    Putting skill measured as strokes gained on the greens.
    Driving distance rating
    DataGolf yards vs an average PGA Tour field (from skill-ratings); when live measured drives exist, the table can show absolute yards instead.
    Accuracy rating
    DataGolf skill-rating driving accuracy value, shown as points versus the field baseline.

    Course fit

    This tab compares how players match the current field and how much this week’s venue profile stresses different parts of the game. Use it when you care whether someone’s strengths line up with what the track tends to reward or punish.

    Two views

    Adjustments — Radar chart, course similarity, and the course ratings table (full field). Past events — Historical round-prop distributions at this course from archived tournament rounds.

    Adjustments

    Golfer selector
    Pick a golfer to overlay their profile on the radar. With no selection you still see how the venue curve differs from the field.
    Course filter
    Choose which venue’s historical profile drives the green venue curve and the similarity list; it defaults to this week’s course from projections.
    Radar
    Each spoke is a skill area (Driving Accuracy, Off Tee, Approach, Around Green, Putting, Driving Distance). The shapes show Field Avg (dashed baseline), the selected course profile (green), an optional comparison course from the similarity list (blue), and your selected golfer (gold). The chart uses normalized profiles (0–1), not strokes gained.
    Course similarity
    A ranked list of other venues whose historical shape is closest to this one. Click a row to highlight it and draw that course’s profile on the radar; click again to clear.

    Course ratings table

    Lists every player in the current tournament field. All numeric cells are course-fit ratings (field-relative scores). They are not strokes gained and are not the same units as SG columns elsewhere in the app.

    Golfer
    Name only. Use the search box to filter.
    Drv Acc, Off Tee, Approach, Arg, Putt, Distance
    One column per radar spoke. Each value is that player’s skill vs the field on that dimension (z-scored across everyone in the table). 0 ≈ average; positive = stronger than the field on that spoke; negative = weaker. These are not strokes gained. See Course rating for overall fit to this venue’s radar profile.
    Course rating
    Overall fit to this venue: each spoke’s field z-score is weighted by that spoke’s demand on the green radar profile (Approach uses iron-play demand, not raw ARG splits), then z-scored across the field. Higher = skills that matter most here, relative to everyone else. Round projections still use the separate course_table SG×coefficient adjustment.
    Winner, Top 5, Top 10, Top 20
    Best available sportsbook outright prices for that player (separate from the rating columns).
    Sort
    Click any column header to sort. Green/red coloring only highlights positive vs negative ratings, not EV or SG.

    Past events

    Analyze Past Events
    Select one or more prior tournaments played at the course in the sidebar (from player-history/by-course shards).
    Round / Round Prop
    Filter to a single round or all rounds, and pick the counting stat (score, birdies, pars, bogeys, fairways, GIR).
    Round Average chart
    One bar per player per event: the mean of that stat across the selected round(s) at that event.
    Individual chart
    Every completed round in the filter window. Shaded bands show ±1 SD and ±2 SD; the red line is the mean.
