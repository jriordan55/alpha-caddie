Quintile lifts (pre-round → next)

  • Score via L3 score: Q1 next avg 69.3 → Q5 next avg 71.6
  • Birdies via L3 birdies: Q1 3.36 → Q5 4.13
  • GIR via last GIR: rate 0.59 → 0.69

Do

  • Use L3 own-market averages as the primary prior
  • For score O/U, blend L3 score + season SG:Total
  • For GIR O/U, overweight last / L3 GIR
  • Within-event SG only after R1 (R2–R4)

Don’t

  • Don’t use same-round SG (not knowable pre-tee)
  • Don’t chase last-round putting for next birdies
  • Don’t expect SG pillars alone to beat counting form
  • Don’t bet pars O/U on SG (|r|≈0.05)
