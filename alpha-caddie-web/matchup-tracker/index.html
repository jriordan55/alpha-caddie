Guide

This tracker mirrors the O/U Projection tracker for round matchups and 3-balls only.

  • Odds source: DataGolf /historical-odds/matchups + live /betting-tools/matchups
  • Books: DraftKings, FanDuel, BetMGM only
  • Model: walk-forward μ_SG (same pipeline as live projections)
  • 2-way: Gaussian win prob (σ_diff = 2.85)
  • 3-ball: softmax on μ_SG (T = 2.05)

Refresh: npm run matchup-tracker:refresh · Local: npm run matchup-tracker
